# Cores na Mão — Sinais das cores em Libras

Página de apoio do jogo **Cores na Mão**. Mostra, em vídeo (GIF), o sinal em Libras de cada cor. O QR code do manual e da caixa aponta para esta página.

## Publicar (GitHub Pages)
1. Suba o arquivo `index.html` neste repositório (e, depois, a pasta `gifs/`).
2. No GitHub: **Settings → Pages → Branch: `main` / pasta `/ (root)` → Save**.
3. Em ~1 minuto a página fica no ar em:
   **https://tiryth.github.io/Coresnamao/**

> Confere se é essa a URL que aparece em Settings → Pages. Se for diferente, me avisa que eu regero o QR.

## Adicionar os GIFs dos sinais
Crie uma pasta chamada `gifs/` e coloque os arquivos com **estes nomes exatos**:

```
vermelho.gif  azul.gif  amarelo.gif  verde.gif  preto.gif
branco.gif    rosa.gif  roxo.gif     laranja.gif  azar.gif
```

Enquanto um GIF não existir, a carta mostra "Adicione o GIF". Assim que o arquivo estiver na pasta, ele aparece sozinho — passar o mouse (no PC) ou tocar (no celular) sobre a cor.

Sugestão de formato: GIF curto em loop, ~400–600 px, mostrando o movimento do sinal.
